## Written from what actually happened

Every page describes what was run and observed on a real cluster, wrong first attempts included. One example, from building the `PostgresDatabase` composition:

> All tenants share one Postgres server. The first version named databases after the claim only, so a team creating a database with the same name in its own namespace silently adopted another team's database, and deleting it dropped theirs. Names are now `<namespace>_<name>`, and the same scenario leaves the victim's data intact.

[Read the full story](/architecture/postgres-database/#server-side-names-a-security-fix).

## Status

IdPlatformKit is a reference implementation, built to be read, run and reused. Its backing services (Postgres, OpenBao) run in single-replica dev mode with fixed local credentials. **It isn't production-ready, and doesn't pretend to be.** The roadmap includes a prod-like profile.
